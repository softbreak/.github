Bazı projeler yalnızca eğitim örneği değildir.

Gerçek bir yazılım ekibindeki gibi:

**Issue → Fork → Branch → Implementation → Pull Request → Engineering Review → Revision → Merge**

akışıyla toplulukla birlikte geliştirilir.

AI araçlarını kullanabilirsin.

Ancak çalışan kod tek başına yeterli değildir.

## 🤝 Contribution

Topluluk projelerinde doğrudan `main` branch üzerinde çalışılmaz.

Genel contribution modeli:

1. Çalışmaya açık Issue'yu incele.
2. Repository'yi fork et.
3. Issue için ayrı bir branch oluştur.
4. Geliştirmeyi ve testlerini tamamla.
5. Kendi fork'una push et.
6. Upstream repository'ye Pull Request gönder.
7. Engineering review sürecini tamamla.
8. Gerekirse aynı branch üzerinden revision yap.

Her repository'nin kendi `README.md` ve `CONTRIBUTING.md` dosyasında proje özelindeki kurallar ayrıca belirtilir.
